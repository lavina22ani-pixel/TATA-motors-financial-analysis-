# TATA-motors-financial-analysis-
Consolidated financial analysis of Tata Motors for FY2021–FY2025 using Microsoft Excel.
## Project Overview

This project presents a five-year consolidated financial analysis of Tata Motors covering FY2021 to FY2025.

The analysis examines the company's revenue, EBITDA, EBIT, profit after tax, total assets, debt, equity and EPS, along with selected financial ratios and trend analysis.

The project was developed using Microsoft Excel, with a supporting financial analysis report prepared in Microsoft Word.
## Data Source

The analysis is based on consolidated financial information published by Tata Motors in its annual reports for FY2021 to FY2025.

The primary source used for the financial data is the official Tata Motors website and its published annual reports.

## Financial Metrics Analyzed

The project analyzes the following financial indicators:

- Revenue

- EBIT

- Total Assets

- Earnings Per Share (EPS)

## Methodology

The financial data was organized in Microsoft Excel using consolidated financial figures for FY2021–FY2025.

The analysis followed these steps:

1. Collected relevant financial data from Tata Motors' published annual reports.
2. Organized the financial data into a structured Raw Data sheet.
3. Calculated selected financial ratios and performance indicators.
4. Analyzed year-on-year trends in revenue and profitability.
5. Created charts to visualize major financial trends.
6. Developed an interactive financial dashboard in Excel.
7. Prepared a supporting financial analysis report in Microsoft Word.

## Key Findings

- Revenue increased from ₹249,795 crore in FY2021 to ₹439,695 crore in FY2025.
- EBITDA margin improved from 12.17% in FY2021 to 13.10% in FY2025, despite fluctuations during the period.
- The company reported negative PAT in FY2021 and FY2022 before returning to positive profitability from FY2023.
- PAT margin reached 7.33% in FY2024 before moderating to 6.40% in FY2025.
- The Debt-to-Equity ratio declined over the period, reaching approximately 0.51x in FY2025 based on the debt and equity figures used in this analysis.
- EPS improved from negative levels in FY2021 to ₹78.80 per share in FY2025.
